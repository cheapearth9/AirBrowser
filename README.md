AirBrowser
A brand new, modern looking browser for iPhone and iPad.
The whole point of me creating this was to recreate AirWeb for free, because apps like AirWeb, XeOS, shiftscreen 4x, etc has always been a great
choice for device that can't extend its display to an external display. However, they cost money (not a lot but still), so i have made this for
people who need something like AirWeb but doesn't need to pay a dime. This browser is also mostly vibecoded.
Features include:
-AirPlay functionality via HDMI and wirelessly
-Most things you would expect from a normal browser (swipe gestures, go back and forward), settings menu has very limited options but will update.
